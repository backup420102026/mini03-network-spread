# Mini Research #3: Network Topology and Information Spread

## Research Question
**How does network topology affect the spread of information in a simulated social network?**

## Overview
This mini research project uses computational simulation to compare information spreading across three synthetic network topologies: Random, Small-World, and Scale-Free.

The study focuses on the effect of network structure on the **speed** and **final extent** of information spread under fixed simulation assumptions. It is a simulation study and is not intended to directly model real-world human behavior.

## Main Results

| Network | Final Spread (%) | Time to 50% |
|---|---:|---:|
| Random | 99.93 | 9.00 |
| Small-World | 100.00 | 9.20 |
| Scale-Free | 100.00 | 5.93 |

### Main Finding
Under the simulated conditions, the **Scale-Free** topology produced the fastest information spread, reaching 50% informed nodes in an average of **5.93 simulation steps**.

All three topologies reached approximately complete spread by the end of the 30-step simulation.

## Experimental Setup
- Nodes: 100
- Topologies: Random, Small-World, Scale-Free
- Transmission probability: 0.20
- Simulation steps: 30
- Runs per topology: 30
- Target spread: 50%
- Random seed: 42
- Total observations: 2,790

## Important Limitation
The generated networks do not have identical edge counts:
- Random: 224 edges
- Small-World: 300 edges
- Scale-Free: 291 edges

Therefore, this is a comparison of standard topology models under the selected generation parameters, not a perfectly controlled equal-edge comparison.
